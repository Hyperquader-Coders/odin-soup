# Patched bindings

The bindings are generated by runic (Amber's fork, branch `amber-patched`) from the C headers.
Two things change the generated output: rules that `make generate` applies every time, and
hand-written code. Regenerating applies the rules again and leaves hand-written files alone;
a typed pin in `soup/patched.odin` makes a regeneration that drops a rule fail to compile.

To regenerate, run `make generate` and then `make ci`.

## Generation rules

`scripts/postprocess.sh soup` applies these to `soup/soup.odin`, in this order. The structure
is odin-glib's; the strings need no rule, because runic maps `gchar *` to `cstring` once
`glib:glib` is the external source.

| rule | reason | pin |
|---|---|---|
| `_SOUP_EXTERN`, `VAR`, `DEPRECATED*`, `AVAILABLE_IN_*`, `GLIB_MKENUMS_EXTERN` deleted | export-attribute macros, no value in Odin | none |
| backticks dropped from `MAJOR_VERSION`, `MINOR_VERSION`, `MICRO_VERSION`, `VERSION_*`, `COOKIE_MAX_AGE_*`, `HSTS_POLICY_MAX_AGE_PAST` | integer macros runic quotes as strings | `patched_cookie_max_age_one_year` |
| `COOKIE_MAX_AGE_ONE_YEAR` is `31556926` | the macro is `365.2422` days, a float that cannot be an `int` argument; C truncates it | `patched_cookie_max_age_one_year` |
| `METHOD_GET`, `METHOD_POST` and the other `METHOD_*` become the string `"GET"`, `"POST"`, … | the macros expand to an interned-string expression | `patched_method_get` |
| `TYPE_FOO :: \`(soup_foo_get_type ())\`` (parentheses optional: `TYPE_SESSION`) becomes `TYPE_FOO :: foo_get_type` | the macro names the type function | `patched_type_message` |
| `SESSION_ERROR`, `TLD_ERROR`, `WEBSOCKET_ERROR` become the `*_error_quark` procedures | as above | `patched_session_error` |
| `HTTP_URI_FLAGS` is `glib.UriFlags{.HAS_PASSWORD, .ENCODED_PATH, .ENCODED_QUERY, .ENCODED_FRAGMENT, .SCHEME_NORMALIZE}` | the macro ORs `G_URI_FLAGS_*` names; the type is odin-glib's flag set | `patched_http_uri_flags` |
| `Cacheability`, `Expectation`, `MessageFlags`, `ServerListenOptions` become `bit_set`s (below) | callers write `{.MESSAGE_IDEMPOTENT}`; the type keeps the C size and bits | `#assert` on the sizes |
| `Foo :: _SoupFoo` is deleted and `_SoupFoo` becomes `Foo` | one name per struct | none |
| Every procedure parameter is `^T` (`^^T` for `T **`) unless `arrays:` lists it (`detect.parameters: declared` in `soup/rune.yml`; no postprocess rule) | runic writes `[^]T` for any pointer parameter whose name ends in "s"; the headers pass one `T *` for `hdrs`, `headers`, `metrics`, `params`, `cookies`, `expires`, `extensions` and the rest. `protocols` (`char **`, NULL-terminated) and `ranges` (`SoupRange *` with a length) are arrays, listed under `arrays:` | `patched_message_headers_append`, `patched_message_metrics_copy`, `patched_multipart_get_part` and one pin for each other parameter |
| `form_encode_valist` is skipped by the fork (a comment marks the place in `soup.odin`) | it takes a `va_list`; the unpatched runic drops it and marks the procedure `#c_vararg ..any`, so a call is wrong. The other `#c_vararg` procedures (`form_encode`, `server_new`, ...) take a real `...` and are correct | `scripts/check-generated.sh` |
| `[^]^T` parameters are checked, not rewritten | as above. `ranges` of `message_headers_get_ranges` is `SoupRange **` with `length`, an out-array of structs: stays | `scripts/check-generated.sh` fails on any other `[^]^T` |

### Flag sets

`bit_sets` in `postprocess.sh` is odin-glib's function (odin-glib's DECISIONS §8 holds the
rules). `SoupMessageFlags :: enum u32 {MESSAGE_NO_REDIRECT = 2, …}` becomes
`MessageFlagsBit :: enum u32 {MESSAGE_NO_REDIRECT = 1, …}` (bit indices) and
`MessageFlags :: bit_set[MessageFlagsBit; u32]`. The list is the four `<bitfield>` entries of
`Soup-3.0.gir`; all four are declared by `soup.h`, have single-bit members and no zero member,
so no constant is added. Generation fails if a listed enum is missing. A field declared
`guint` is not a flag type and stays an integer.

Hand-written code: none.
