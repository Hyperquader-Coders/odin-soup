# Spec — odin-soup

## Packages

```
soup/   package soup: generated by runic from soup/rune.yml
```

Import through the `soup` collection: `import "soup:<package>"`.

## Surface

Every public declaration of the bound headers (libsoup 3 3.4.4), named as runic names
them, plus the hand fixes in [PATCHED.md](PATCHED.md). Deprecated API is bound, because
`GLIB_DISABLE_DEPRECATION_WARNINGS` is set when generating.

## Flags

`Cacheability`, `Expectation`, `MessageFlags` and `ServerListenOptions` are `bit_set`s of a
`FooBit` enum: `soup.message_add_flags(msg, {.MESSAGE_IDEMPOTENT})`. DECISIONS §5.

## Version

The binding records the library version it was generated from. `make test` compares it
with the version macros of the installed headers.
